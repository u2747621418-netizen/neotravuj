# NEOTRAVUJ 2.0 – web

## Spustenie
1. Rozbaľ ZIP.
2. Otvor súbor `index.html` v prehliadači.
3. Nič netreba inštalovať.

## Súbory
- `index.html` – hlavná stránka
- `style.css` – vzhľad a animácie
- `script.js` – odpovede, počítadlo, zvuk a tlačidlá

## Poznámka
Počítadlo sa ukladá iba do LocalStorage daného prehliadača. Web nevyžaduje server ani databázu.

## Ďalší krok
Pre verejnú adresu `www.neotravuj.sk` treba web nahrať na hosting a nastaviť vlastnú doménu.
